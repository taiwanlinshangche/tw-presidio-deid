# Markdown 本機去識別化工作台

分享文件前，先把姓名、電話、電子郵件、公司名稱等資訊遮起來。這個工具會在你的電腦上找出疑似個資，你再決定哪些要隱藏，最後下載處理好的 Markdown 檔案。

**不需要會寫程式、不需要 GitHub 帳號，也不需要申請 AI 金鑰。** 第一次安裝需要網路；安裝完成後，文件辨識在自己的電腦上進行，不會把文件上傳到雲端。

**[下載最新版 ZIP](https://github.com/taiwanlinshangche/tw-presidio-deid/archive/refs/heads/main.zip)** · [專案首頁](https://github.com/taiwanlinshangche/tw-presidio-deid)

> 第一次使用：下載 → 解壓縮 → 開啟啟動檔 → 按「安裝全部」→ 按「開始」→ 用「模擬測試」試一次。
>
> 自動辨識可能漏掉資料。只有你選取遮罩的文字才會被替換，分享匯出檔前仍要檢查全文。

## 1. 先確認你的電腦

| 項目 | Mac | Windows |
| --- | --- | --- |
| 系統 | macOS 14 或更新版本 | Windows 10／11，x64 電腦 |
| 晶片 | Apple Silicon，例如 M1、M2、M3、M4 | Intel／AMD 的 64 位元處理器 |
| 啟動檔 | `start.command` | `start.bat` |
| 驗證狀態 | 已有本機 Mac 使用與測試紀錄 | 已提供啟動器，尚未完成真實 Windows 電腦的完整驗收 |

- 預留約 **5 GB 可用空間**，供模型、執行環境與安裝暫存使用；實際占用依系統而異。
- 第一次請保持連網，預留數十分鐘，速度取決於網路與電腦。
- 不用事先安裝 Git、Homebrew、Node.js 或 Python，啟動器會準備所需環境。
- Intel Mac、Windows ARM、Linux、手機與平板目前不在支援範圍。

Mac 可點左上角 Apple 選單 →「關於這台 Mac」，查看晶片與 macOS 版本。Windows 可到「設定」→「系統」→「關於」，查看「系統類型」是否為 x64 處理器。

## 2. 下載到你的電腦並解壓縮

1. 點上方的 **「下載最新版 ZIP」**，下載 `tw-presidio-deid-main.zip`。如果瀏覽器詢問存放位置，選「下載項目」或「下載」。
2. 下載完成後，找到這個 ZIP 檔案：
   - **Mac**：在 Finder 的「下載項目」中，按兩下 ZIP 解壓縮。若瀏覽器已自動解壓縮，就直接使用解出的資料夾。
   - **Windows**：在檔案總管的「下載」中，對 ZIP 按右鍵 →「全部解壓縮」→「解壓縮」。
3. 把解出的 **`tw-presidio-deid-main` 整個資料夾**放到固定位置，例如「文件」。第一次安裝後，盡量不要再移動或改名。
4. 打開資料夾，確認裡面看得到 `start.command`、`start.bat`、`backend`、`scripts` 等檔案與資料夾。

**必須先解壓縮；不要在 ZIP 裡直接執行，也不要只把啟動檔單獨拉出來。** 若外面還多包了一層資料夾，往裡面打開，直到看到啟動檔。

也可以從 [GitHub 專案首頁](https://github.com/taiwanlinshangche/tw-presidio-deid) 按綠色 **Code** → **Download ZIP**，下載的是同一份專案。

## 3. 開啟工具

只需要看符合你電腦的步驟。

### Mac

1. 在解壓縮後的資料夾裡，按兩下 **`start.command`**。
2. 若顯示無法驗證開發者而被阻擋，先關閉提示，再到 Apple 選單 →「系統設定」→「隱私權與安全性」。確認是剛從本專案下載的檔案後，在對應的阻擋提示旁按 **「仍要打開」**，依畫面完成確認。不同 macOS 版本的文字可能略有差異，可參考 [Apple 官方開啟說明](https://support.apple.com/zh-tw/102445)。
3. 會出現「終端機」視窗，開始顯示啟動或下載訊息。**請保留這個視窗，不要關掉。**
4. 等瀏覽器自動開啟工作台。第一次可能要先下載執行環境，網頁不會立刻出現。

如果顯示「沒有執行權限」或「Permission denied」：

1. 打開「終端機」（可用 Spotlight 搜尋）。
2. 輸入 `chmod +x `，注意最後要有一個空格，先不要按 Enter。
3. 把資料夾裡的 `start.command` 拖進終端機視窗，讓它自動填入完整路徑。
4. 按 Enter，再回到資料夾開啟 `start.command`。

若啟動檔只被文字編輯器打開，可對它按右鍵 →「打開檔案的應用程式」→「終端機」。

### Windows

1. 在解壓縮後的資料夾裡，按兩下 **`start.bat`**。
2. 如果隱藏副檔名，可能會看到兩個名為 `start` 的檔案；請選類型為「Windows 批次檔」的那個。也可以先在檔案總管的「檢視」開啟「副檔名」顯示。
3. 如果出現「Windows 已保護您的電腦」，確認檔案是從本專案下載後，按 **「其他資訊」→「仍要執行」**。若是公司管理的電腦且沒有這個選項，請由管理人員協助。
4. 會出現命令提示字元／PowerShell 視窗。**請保留這個視窗，不要關掉。**
5. 等瀏覽器自動開啟工作台。第一次可能要先下載執行環境。

## 4. 完成第一次安裝

瀏覽器打開後，會看到十張環境檢查卡片。

1. 等檢查跑完。第一次有紅色「缺少或損壞」或「尚無法檢查」的卡片，通常表示必要元件還沒裝好。
2. 按卡片下方的 **「安裝全部」**。
3. 等待 Python、辨識套件與中文模型下載、安裝。過程會顯示進度；請保持網路連線，保留啟動視窗與瀏覽器分頁。
4. 全部卡片變綠後，畫面中央會出現 **「開始」**，按下去就能使用。

如果電腦上的環境已完整，檢查通過後可直接按「開始」，不會再出現安裝按鈕。

安裝中斷或失敗時，先確認網路與磁碟空間，再按 **「重試安裝」**。程式會重新檢查並沿用已完成的項目。

## 5. 先用範例試一次

沒有自己的文件也可以先玩：

1. 按「開始」後，畫面會顯示 **「把 .md 拖進來」**。
2. 按下面的 **「模擬測試」**，載入內建的示範提案。
3. 等辨識完成。文件裡的疑似個資會有標記。
4. 點一下某個標記，文字會變成像 `〔姓名 1〕` 的代稱；再點一次可以還原。
5. 按右上角的 **向下箭頭下載圖示**，下載處理好的 `.md` 檔案。

範例中的「青嶼市青年發展局」是虛構機關，人名、聯絡方式與數字為合成資料，不代表正式提案或合作。

## 6. 處理自己的文件

### 放入文件

- 把一個 **`.md` 檔案**拖進「把 .md 拖進來」區域，或點這個區域選檔。
- `.md` 是 Markdown 文字檔；目前不直接支援 Word、PDF、Excel、圖片或掃描文件，也不提供這些格式的轉換。**把 `.pdf` 或 `.docx` 改名成 `.md` 不會完成轉換。**
- 一次處理一個檔案，需為 UTF-8 編碼，檔案上限為 2 MiB，單次辨識最多 30,000 個 Unicode 字元。

### 選擇要遮掉的資訊

工具會嘗試找出姓名、組織、地點、臺灣電話、電子郵件、身分證字號、統一編號等疑似資料。**被標記只代表找到候選項目，還不等於已遮罩。**

| 想做的事 | 操作方式 |
| --- | --- |
| 遮掉一段被標記的文字 | 點一下標記；再點一次還原 |
| 同樣的文字一起處理 | 保持右上角「閃電模式」開啟（預設開啟），點一處會一起切換同組文字 |
| 只處理其中一處 | 先關閉閃電模式，再點那一處標記 |
| 整類一起處理 | 點右上角標籤圖示「分類快速遮罩」，再點分類，例如姓名或組織 |
| 同一個標籤全部一起處理 | 在分類面板中點該標籤，會切換整份文件裡的同組文字 |
| 檢查原本的 Markdown 或修改文字 | 切到「原始碼」，直接編輯；停止輸入後會套用並重新辨識 |
| 用排版後的畫面閱讀 | 切到「預覽」；點未被標記的段落也可以編輯，點段落外套用，按 Esc 取消 |

分類面板的操作永遠以整類／整組為單位，不受閃電模式影響。編輯內容並重新辨識後，請再檢查遮罩結果。

### 下載並檢查結果

1. 選好要遮的地方後，按右上角 **向下箭頭下載圖示**。
2. 有選取遮罩時，會下載 **`[去識別] 原檔名.md`**。例如原檔為 `提案.md`，新檔為 `[去識別] 提案.md`。
3. 檔案通常在「下載項目／下載」；若瀏覽器詢問儲存位置，依你選擇的位置存放。找不到時可打開瀏覽器的下載清單。
4. 用文字編輯器開啟下載檔，或關閉目前文件後把下載檔重新拖進工具，確認想隱藏的資訊已被代稱取代，再分享給別人。

**沒有選取任何遮罩，就不會產出去識別化的內容。** 未編輯也未遮罩時，下載的是 `原檔名-原文.md`；只有編輯、沒有遮罩時，下載的是沿用原檔名的編輯版。

工具會產生下載檔，不會直接覆寫你拖入的來源檔。沒有被選取的資訊、模型漏掉的資訊，以及 Markdown 內的連結網址等，都可能仍存在匯出內容中；請檢查原始文字，不能只看畫面上的遮罩。

## 7. 關閉與下次使用

- **換另一份文件**：先下載目前成果，按左上角「關閉」，再選擇另一個 `.md`。
- **結束使用**：先下載要保留的成果，關閉瀏覽器分頁，再到啟動視窗按 `Control + C`（Mac 也是 Control，不是 Command），或關閉啟動視窗。
- **下次使用**：回到同一個資料夾，開啟 `start.command`（Mac）或 `start.bat`（Windows），等檢查完成後按「開始」。已安裝的元件會沿用。

**編輯與遮罩狀態不會自動存檔。** 關閉文件、重新整理或關掉分頁前，請先下載成果。只關閉瀏覽器分頁，不一定會停止背景服務；要完整結束請一併停止啟動視窗。

## 常見問題

### 瀏覽器沒有自動開啟，或說無法連線？

先確認啟動視窗還開著，且沒有顯示失敗訊息。如果還在下載，等它完成；若已顯示工作台網址，把那個網址複製到瀏覽器。

通常是 `http://127.0.0.1:4173`，但連接埠被占用時會換一個，**以啟動視窗顯示的網址為準**。`127.0.0.1` 代表你自己的電腦，朋友不能直接使用你電腦上的這個網址，必須在他的電腦啟動工具。

請從啟動檔開啟，不要直接點 `index.html`；單獨開啟網頁檔無法啟動辨識服務。

### 安裝卡住或出現錯誤？

確認網路可用、磁碟空間足夠，再看是哪張卡片失敗，按「重試安裝」。模型下載與首次載入可能需要較久時間。

若仍失敗，記下卡片名稱與啟動視窗最後的錯誤訊息，再向分享工具的人求助。提供截圖時不用附上正在處理的私人文件。

### 顯示「另一個初始化程序正在執行」？

先找出之前開啟的啟動視窗，等待安裝完成，或正常停止後再重開。不要同時重複點擊啟動檔。

### 為什麼下載只有幾 MB，安裝後卻變成幾 GB？

ZIP 裡是程式和介面；第一次使用時，另外下載能在本機執行 AI 的模型與環境。這些主要放在專案的 `.runtime` 隱藏資料夾，安裝後變大是正常的。使用期間不要刪除它，否則之後可能需要重新安裝。

### 文件會傳到網路上嗎？需要付 AI 費用嗎？

這個工具不需要 AI API 金鑰或訂閱，文件只送到自己電腦上的辨識服務。第一次安裝會連網下載軟體與模型，安裝完成後可離線辨識。

文件內容不會由應用程式存入資料庫、localStorage 或應用程式日誌；你下載的檔案則會保存在你選擇的位置。畫面遮罩不是加密，原文在開啟中的分頁記憶體裡仍可能存在。

### 沒有標記的資料能手動處理嗎？

可以切到「原始碼」，自行刪除或把文字改成代稱，等重新辨識完成後再下載。工具可能漏判或誤判，特別是罕見姓名、簡稱、跨格式文字與其他語言。

### 如何更新？

**用 ZIP 下載的人：**

1. 先下載工作成果並停止工具。
2. 重新點 README 上方的「下載最新版 ZIP」，解壓縮到另一個資料夾，保留舊資料夾作備份。
3. 直接開啟新資料夾的啟動檔並完成安裝，是最簡單的方式，但會重新下載必要環境。
4. 想沿用模型與環境時，可在同一台電腦上，把舊資料夾的 `.runtime` **整個複製**到新資料夾，再啟動並依檢查結果補裝。Mac 可按 `Command + Shift + .` 顯示隱藏檔案。若檢查顯示環境路徑失效，改用全新解壓縮的資料夾重新安裝。
5. 確認新版正常、成果已另存後，再自行決定是否刪除舊資料夾。

**原本用 Git 下載的人：** 停止工具，在專案資料夾執行 `git pull --ff-only`，再開啟啟動檔。如果提示本機有修改，先備份並確認差異，不要直接丟棄修改。

### 如何移除？

先停止工具，另存你要保留的文件，再刪除專案資料夾；專案內的模型與環境會一併移除。瀏覽器下載資料夾中的匯出檔需自行管理。

# Windows

### 資料處理邊界

服務僅綁定 `127.0.0.1`；一般模式由 Node.js 轉送本機 API，檢查 Host、Origin、JSON 與自訂標頭，不開放 CORS。Markdown 預覽不執行原始 HTML、不自動載入圖片，也不提供外部連結跳轉；匯出仍需檢查原始 Markdown 內容。

單次辨識最多 30,000 個 Unicode 字元、1,200 個候選區間，超出時拒絕而不截斷。中文模型負責人名、組織與地點，另外以臺灣格式規則與明確欄位補充辨識；日期、預算及所有個資種類不在完整覆蓋承諾內。
